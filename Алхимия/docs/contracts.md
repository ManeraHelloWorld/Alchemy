# Shared module contracts

Buildless ES modules in dist/. World canvas 1200 x 620 logical pixels. Table surface y=490; side bounds x=30..1170. Physics units pixels/seconds. Positive angle clockwise radians, upright angle=0. Ambient 22 C. Front facing fixed laboratory.

chemistry.js exports SUBSTANCES (object keyed id, each id,name,formula,color,state,category,description), REACTIONS (array); createMixture(id, volume=80), volume(mix), color(mix), describe(mix), transfer(source,target,amount), stepChemistry(mix,dt,options={heating:0,sealed:false}), getPH(mix). Mixture {amounts:{id:number},temperature:22,...}; quantities are educational simulation amounts; document limitations. stepChemistry returns array of {type:'reaction'|'gas'|'boil'|'explosion'|'precipitate',title,equation,description,intensity,color}. Allowed reactions only; no invented reactions. No hazardous synthesis recipes. Methods tolerate empty mixtures. transfer conserves proportional amounts and mixes temperature. Known ids water,hcl,naoh,cuso4,iron,sodium_bicarbonate,acetic_acid,sodium_chloride,calcium_carbonate,phenolphthalein.

physics.js imports chemistry, exports World, EQUIPMENT. World constructor(onEvent). world.bodies=[], particles=[], puddles=[], held=null, selected=null, time=0, paused=false. Body {id,kind:'bottle'|'beaker'|'flask'|'tube'|'burner'|'stand',x,y,w,h,angle,vx,vy,angularVelocity,mixture,capacity,label,formula,color,sealed:false,lit:false,broken:false}; center x/y. create(kind,x,y,{substance,volume,label}) pushes and returns body. remove(body); pick(x,y) sets held + selected and returns body; move(x,y); rotate(deltaRadians); release(); step(dt); clear(); serialize(); restore(data). click pick persists after mouseup, right click releases. Floor collision, angular physical settling, body collisions, transfer from tilted vessel mouth to upright target, spills onto floor, burner heats bodies above lit burner, break on hard impact and flash/particles explosion. callback onEvent({type,title,description,equation,body}). EQUIPMENT array {id,name,description,capacity}. Quantities limited by capacity, geometry rotation consistent. No dependencies. addParticle optional. Root UI controls sealed/lit directly. Wipe puddles with world.puddles=[]; inventory remove/create/restore handled UI. selected set on pick, remains after release.

renderer.js exports Renderer constructor(canvas), draw(world,opts={showHints:true}), drawItem(canvas,bodyOrSpec). draw uses supplied world and renders entire beautifully detailed pixel laboratory incl fixed background, foreground table, props, dynamic vessels/liquids rotated with level surface, particles, puddles, cursor highlight, heated glow, shadows, warm lighting. drawItem static for inventory and catalog. Canvas main logical size 1200x620 set in constructor; CSS pixelated. Body drawing dimensions per physics; read physics.js when exists. Renderer must tolerate missing optional fields. Canvas no DOM UI overlays except tiny object labels. All labels Russian. UI implements chrome outside canvas.

Root owns index.html, style.css, app.js, server.mjs, README. Agents own their assigned module and tests, no editing others' modules.
